# Project Overview: Squad Creatives

Squad Creatives is a CAC-registered Nigerian digital agency offering full-service design, software engineering, and digital strategy. The website serves as both the agency's front door and a showcase for internal products under active development (Ryzon, Tripa, Duella).

## Core Architecture & Tech Stack
- **Frontend**: Semantic HTML5, Vanilla CSS3 (Custom design system using CSS variables, IBM Plex Mono & Space Grotesk fonts), Vanilla JS (ES6 DOM manipulation).
- **Form Submissions**: Integrated with Web3Forms API endpoint.
- **Media & Assets**: Custom SVG diagrams, local team photography in `images/`, high-fidelity prototype images in `images/prototypes/`.

## Key Features & User Journeys
1. **Agency Credibility & Registration**: Display of official CAC Business Name registration details (`RC/BN 7237172`).
2. **Interactive Workbench Process**: Interactive 4-phase development roadmap console with visual diagrams and high-fidelity prototype view states.
3. **Team Spotlight**: Dynamic layout spotlighting agency leadership with expandable team roster and touch-enabled profile popups.
4. **Product Showcase (In-House)**: Highlighting internal fintech, mobility, and web3 products under development (Ryzon, Tripa, Duella).
5. **Client Lead Intake**: Direct appointment booking via Calendly link or structured form submission via Web3Forms.

## Conventions
- Native HTML/CSS/JS with zero build steps or heavy frameworks.
- Cyberpunk/Blueprint dark aesthetic (`#061122`, `#0A1930`, `#1D4ED8`, `#7FD79A`).
- Accessible keyboard navigation and mobile-first touch overrides.
